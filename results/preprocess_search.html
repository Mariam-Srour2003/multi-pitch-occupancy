Why these switches

Each is a hypothesis about what does not travel between venues.

SwitchHypothesis

The switches interact, which is why this is a search and not a table. Measured separately on DINOv2, grayscale gained +0.022 and a centre crop +0.038 — but applied together they scored 0.061 below the untouched baseline, with the worst fold falling from 0.99 to 0.67. Removing information has a floor, so the best set cannot be read off one-at-a-time results.

Greedy search is used because each candidate needs a fresh embedding pass over the dataset. It can still miss a pair that only helps jointly; run --pairs for an exhaustive pass over the survivors.
