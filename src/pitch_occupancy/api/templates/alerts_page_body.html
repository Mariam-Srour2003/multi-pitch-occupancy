What alerts are for. You should not have to keep this dashboard open to find out something is wrong. When something needs attention, the system sends one short message to Slack, Microsoft Teams, Discord, email, or - through an automation service - WhatsApp, Telegram or SMS. It checks every few minutes while the server is running.

What you are told about

EVENTS

The same problem is not repeated on a channel for a few hours (6 by default), so a camera that stays dark sends one message, not one every five minutes. An anomaly and a daily summary are only ever sent once. During quiet hours nothing is sent; whatever is still a problem when they end is sent then.

Where alerts go

The settings live in a file on this computer, configs/alerts.json, which is never shared or uploaded: a webhook address works like a password for its channel, and an email login has a password. Addresses are shown here as their first part only.

How to set up alerts

Create configs/alerts.json with one or more of these channels (several can sit side by side under channels), restart the server, and press Send a test alert. events chooses which alerts go to that channel; min_severity can be info, warning or serious.
